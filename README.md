## Projects

### 🤖 WhatsApp AI Agent *(in progress)*
Autonomous customer service agent built with n8n, Claude API, and PostgreSQL. Receives WhatsApp messages, validates customers, aggregates multi-message conversations, queries a product catalog, qualifies leads, and replies — without human intervention.

`n8n` `Claude API` `PostgreSQL` `Evolution API` `Railway` `JavaScript`

---

### [🖐 EduBra — Braille Educator Device](https://github.com/Arthur-Heberle/Oficinas_1)
Assistive hardware system that converts digital text into tactile braille output using a Raspberry Pi 4. Built with multi-threading and hardware interrupts to handle concurrent servo-motor actuation and audio feedback without blocking the main thread.

`Python` `Raspberry Pi` `Multi-threading` `Hardware Interrupts` `Wi-Fi`

---

### [🎮 Brasilore — 2D Platformer Engine](https://github.com/Arthur-Heberle/Brasilore)
2D platformer built in C++ with SFML. Applied strict OOP design patterns to separate game logic from rendering, with memory-efficient state handling and file management.

`C++` `SFML` `OOP` `Design Patterns` `Memory Management`
